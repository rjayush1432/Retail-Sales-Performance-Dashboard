Retail Sales Performance Dashboard
Overview

This project is an interactive Tableau dashboard designed to analyze retail business performance. It provides insights into sales, revenue, profit, customer behavior, product performance, and inventory management through dynamic visualizations and KPIs.

Features
Sales & Revenue Analysis
Profitability Tracking
Product Performance Insights
Customer Behavior Analysis
Inventory Management Metrics
Interactive Filters and Dashboards
Tools Used
Tableau
Microsoft Excel
Data Analytics
Business Intelligence
Key KPIs
Total Sales
Total Revenue
Total Profit
Profit Margin
Average Order Value
Inventory Turnover Ratio
Stock Coverage Days
Outcome

The dashboard helps identify trends, top-performing products, customer purchasing patterns, and inventory efficiency, enabling data-driven business decisions.


Interactive Tableau dashboard for analyzing retail sales, revenue, profit, inventory performance, customer behavior, and key business KPIs through data-driven visualizations.
